# 3.6 Testing

## MS1 Demo Test

```bash
# 1. Deploy
./scripts/deploy-all.sh ms1

# 2. Check status
./scripts/dev-status.sh ms1

# 3. Access Keycloak
./scripts/dev-portforward.sh ms1
# Open http://localhost:8080, login admin/admin

# 4. Install and test CRD
kubectl apply -f charts/keycloak-client-operator/crds/
kubectl apply -f examples/client-example.yaml -n keycloak-ms1
kubectl get keycloakclients -n keycloak-ms1

# 5. Cleanup
./scripts/cleanup.sh ms1
```

## Expected Results
- [ ] PostgreSQL cluster healthy
- [ ] Keycloak pod ready
- [ ] Admin console accessible
- [ ] CRD installed
- [ ] Client resource created

## Known Limitations (PoC)
- CRD exists but no operator (no sync to Keycloak)
- Hardcoded admin password
- No TLS (dev mode)
